# 大六壬起課與解卦 Skill

大六壬起課、排盤與解卦的 AI Skill：程式負責排盤（確定性計算），AI 負責解卦。

## 做到什麼程度

- **自動起課排盤**：依時間算月將、天地盤、四課、九宗門三傳、十二天將、遁干、六親、旬空、神煞；沒給時間就以現在起課，也支援指定公曆時間、報時/報數起課、直接給日干支/占時/月將、本命與行年。
- **課體判斷**：九宗門取三傳並判斷課名與格局，例如元首、重審、知一、涉害、見機、察微、蒿矢、彈射、虎視轉蓬、冬蛇掩目、別責、八專、伏吟等。
- **依占問解卦**：先定類神，再看發用、三傳流轉、干支主客、課體格局、年命，最後給一句結論、依據、建議與應期；解讀引用的每個論據都要能在課中找到。
- **輸出排盤圖**：`--png` 可輸出排盤圖 PNG，也支援 `--json` 機器可讀結果。

## 使用

```bash
pip install lunar_python pillow
python3 scripts/liuren.py -q "占問事項"
python3 scripts/liuren.py --date "2026-10-27 13:44" -q "占問事項" --png chart.png
```

詳細起法、選項與解卦流程見 `SKILL.md`，查表見 `references/`。
